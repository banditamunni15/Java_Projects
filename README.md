<h1>PROJECT 1:🎯 Random Number Guessing Game</h1>

<p>
A simple <b>Number Guessing Game built using Java</b>.
The computer randomly selects a number between <b>1 and 100</b>,
and the player has to guess the number.
</p>

<h2>🎮 How It Works</h2>

<ol>
  <li>The computer generates a random number between <b>1 and 100</b>.</li>
  <li>The user enters their guess.</li>
  <li>The program compares the guess with the secret number.</li>
  <li>If the guess is too high, it displays <b>Too High</b>.</li>
  <li>If the guess is too low, it displays <b>Too Low</b>.</li>
  <li>The game continues until the correct number is guessed.</li>
  <li>The program displays the total number of attempts.</li>
</ol>

<h2>🛠️ Technologies Used</h2>

<ul>
  <li><b>Java</b></li>
  <li><code>Scanner</code> - for taking user input</li>
  <li><code>Math.random()</code> - for generating the secret number</li>
</ul>
